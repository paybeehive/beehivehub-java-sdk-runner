# Payloads

Example request bodies used by the runner. Edit these files to test different scenarios.

| File | Description |
|------|-------------|
| `transaction-create.json` | Create a new transaction |
| `customer-create.json` | Create a new customer |
| `recipient-create.json` | Create a new recipient |
| `recipient-update.json` | Update a recipient |
| `bank-account-create.json` | Add a bank account to a recipient |
| `transfer-create.json` | Create a transfer (recipient only) |
| `transfer-create-with-account.json` | Create a transfer with a specific bank account |
| `payment-link-create.json` | Create a payment link |
| `payment-link-update.json` | Update a payment link |
| `company-update.json` | Update company information |
| `delivery-update.json` | Update transaction delivery status |

All monetary values are in **cents** (e.g., R$ 100,00 = `10000`).
